# 🌱 메모리콩 0.4.0

RP가 끝나면 AI가 핵심 기억을 알아서 정리하는 SillyTavern 확장입니다. 새로 중요한 것은 기억하고, 달라진 것은 갱신하고, 해결된 일은 지난 기억으로 옮깁니다. 새 자동 기억을 하나씩 승인할 필요가 없습니다.

## 처음에는 이것만

1. `메모리콩 → 설정`에서 **자동 기억 · 이전 대화 정리용 프로필**을 선택합니다. 실리태번에 미리 저장한 연결 프로필이 표시됩니다. 별도 프로필을 고르지 않으면 현재 메인 API를 사용합니다.
2. 상단의 **자동 기억**을 켜고 평소처럼 RP하세요. 기본값은 켜짐입니다. 처음 연 채팅은 앞으로 오가는 대화부터 관리합니다.
3. 이미 쌓인 대화도 기억하게 하려면 설정의 **이전 대화 전체 가져오기**를 한 번 누르세요. 읽은 내용을 후보 승인 없이 자동 반영합니다.

현재 기억은 다음 RP에 참고 자료로 전달됩니다. 잘못된 항목이 보일 때만 수정하거나 삭제하면 됩니다. 직접 추가·수정한 기억은 자동 변경되지 않도록 보호합니다. AI가 다시 관리하게 하려면 **보호 해제**를 누르세요.

자동 기억에는 **Jev 키가 필요 없습니다**. Jev는 선택 기능인 ‘답변을 보여주기 전에 검수’에만 사용합니다. 수집·정리·번역 API와 RP용 메인 API를 따로 쓸 수 있습니다.

## 어떻게 기억하나요?

| RP에서 생긴 일 | 처리 |
| --- | --- |
| 내일 역에서 만나기로 약속 | 아직 남은 약속으로 저장 |
| 역으로 갈 준비만 함 | 약속 유지, 완료로 바꾸지 않음 |
| 실제로 역에서 만나 약속을 이행 | 완료 처리하고 지난 기억으로 이동 |
| 손을 다침 → 치료 후 완전히 회복 | 회복 상태로 갱신, 부상 기록은 지난 기억으로 이동 |
| 비밀을 상대에게 알려 줌 | 해당 인물의 지식 상태 갱신 |
| 결과가 불분명함 | 기존 기억 유지 |

기억은 중요한 사실, 현재 상황, 약속·할 일, 알게 된 정보로 구분합니다. AI는 기존 기억과 새 대화를 함께 보고 변경분을 제안합니다. 원문에 있는 근거 문구와 출처가 확인되고 설정한 확신 기준을 통과한 제안만 적용합니다. 이것은 형식·출처 검증이며 내용의 진실성을 보장하는 증명은 아닙니다. AI가 거짓말이나 완료 여부를 잘못 판단할 수 있습니다.

새 기억은 한국어로 짧게 요약합니다. 약속·계획은 실제 완료와 구분하고, 언급되지 않았다는 이유만으로 약속을 없애지 않도록 지시합니다. 시간·날짜를 시스템 시계로 추정해 약속을 자동 종료하지 않습니다.

## 화면

- **지금 기억**: 현재 사용 중인 기억. 수정·보호·잠시 끄기·삭제가 가능합니다. `지금 정리`는 아직 처리하지 않은 완료된 RP를 정리하거나 실패한 작업을 재시도합니다.
- **지난 기억**: 완료·취소된 약속, 이전 상태와 변경 근거. `현재 기억으로 복원`하면 보호된 현재 기억으로 복원됩니다. 이미 최신 상태가 연결되어 있으면 그 상태를 갱신합니다.
- **설정**: 기억·번역용 프로필, 기억 전달 여부, 이전 대화 가져오기, 선택형 Jev 검수.

이전 버전에서 모아 둔 미승인 후보는 지난 기억 탭 아래에 그대로 보관합니다. 기존 승인 기억과 번역, 연결 프로필 설정도 유지합니다. 자동 기억을 끄면 다음 답변에 기억을 전달하는 것도 중단하며 저장된 데이터는 남습니다. Jev 검수는 별도 설정입니다.

마법봉 팝업은 가운데에 표시되며 최대 너비 540px, 최대 높이 660px 및 화면 높이의 80% 이내입니다. 내용이 길면 팝업 안에서 스크롤됩니다. 색상은 실리태번 테마를 따르고 글씨 그림자는 없습니다.

## 자동 정리와 되돌리기

- 완료된 캐릭터 답변 이후에 정리를 예약하며, 일반 생성이 끝난 뒤 실행합니다. 아직 답변이 오지 않은 사용자 메시지만으로 새 정리를 확정하지 않습니다.
- 새로 들어온 대화만 처리합니다. 오래된 대화 가져오기는 최대 40개 메시지·18,000글자씩 나누며 긴 단일 메시지도 이어서 읽습니다.
- 이미 처리한 출처가 리롤·수정·삭제로 바뀌면 관련 자동 변경을 역순으로 되돌리고, 바뀐 대화를 다시 처리합니다. 직접 수정·보호한 기록은 자동으로 덮어쓰지 않습니다.
- 채팅 전환이나 정리 도중의 출처 변경을 감지하면 오래된 응답을 저장하지 않습니다.
- AI 응답 형식 오류나 연결 실패 시 해당 묶음의 처리 위치를 넘기지 않습니다. 완료한 묶음은 저장돼 있고 `지금 정리`로 재시도할 수 있습니다. `정리 중단`은 진행 중인 묶음을 끝내고 멈춥니다.
- 새로 추가되는 활성 기억은 최대 80개입니다. 프롬프트는 핵심 15~25개 수준으로 유지하도록 요청합니다. 전달할 때는 보호·관련성·중요도 등을 고려해 최대 20개, 기억 데이터 약 5,500글자로 제한합니다. 관련성 선택은 단어 매칭을 포함한 우선순위 방식이므로 필요한 기억을 놓칠 수 있습니다.
- 지난 기억은 삭제하지 않고 보관합니다. 현재 답변에 다시 전달하지 않지만 사용자가 복원할 수 있습니다.

정리 작업은 RP 답변 뒤에 추가 API 호출을 사용합니다. 보통 짧은 한 교환은 정리용 호출 1회지만 긴 대화는 여러 묶음이 됩니다. 정리가 진행 중인 상태에서 다음 일반 생성을 시작하면 현재 정리가 끝날 때까지 기다린 후 최신 기억을 전달합니다. 과거 대화 전체를 가져오거나 번역하는 동안에는 작업을 먼저 마치는 편이 좋습니다.

## 연결 프로필과 번역

추출·정리용 프로필과 번역용 프로필을 각각 선택할 수 있습니다. 번역 기본값은 ‘사실 추출용 프로필과 동일’입니다. 프로필 목록이 비어 있으면 실리태번의 연결 프로필을 먼저 저장하고 목록 새로고침을 누르세요.

별도 프로필은 메인 RP 연결을 전환하지 않고 실리태번 연결 관리자 요청 서비스를 통해 호출합니다. 프로필이 삭제되었거나 요청에 실패하면 메인 API로 자동 우회하지 않습니다. 프로필의 API 키와 모델은 실리태번에서 관리합니다.

‘한국어 번역’은 접어서 표시합니다.

- **전체 번역**: 저장된 현재·지난 기억, 기존 후보와 출처를 다시 번역합니다.
- **미번역본 전체 번역**: 번역이 없거나 원문이 바뀐 항목만 처리합니다.
- 원문은 보관하며 RP 채팅 자체를 번역하지 않습니다. 완료한 번역은 묶음별로 저장합니다.

## 선택 기능: Jev 답변 검수

설정에서 Jev 키를 입력하고 연결 확인 후 ‘답변을 보여주기 전에 검수’를 켤 수 있습니다. 자동 기억과 별개의 기능입니다.

현재 활성 기억이 있으면 일반 생성을 보류하고 메인 AI의 숨은 초안을 만듭니다. Jev가 관련 사실을 골라 설정 충돌과 명시된 지식 누출을 검사합니다. 충돌이 있으면 메인 AI에 한 번 수정을 요청하고 다시 검사합니다. 오류나 미해결 충돌이 있으면 초안을 표시하지 않습니다. AI 판정이므로 모든 충돌을 잡아내지는 못합니다.

이 기능은 일반 생성만 대상으로 하며 그룹 채팅, 스와이프, 이어쓰기, 재생성은 검수 범위 밖입니다. 숨은 생성은 일반 생성과 프롬프트가 완전히 같지 않을 수 있습니다. 다른 확장의 프롬프트를 읽거나 복원하는 기능은 없습니다. 자동 기억의 리롤 출처 정리와 생성 전 Jev 검수는 서로 다른 기능입니다.

## 설치와 업데이트

**서버 플러그인은 필요 없습니다.** GitHub 저장소 최상위에 아래 **7개 파일**을 올리세요. ZIP 자체나 상위 폴더를 올리지 않습니다.

- manifest.json
- index.js
- core.js
- memory-engine.js ← 0.4.0에서 추가됨
- settings.html
- style.css
- README.md

실리태번의 `확장 → 확장 설치`에는 ZIP 링크가 아닌 GitHub 저장소 URL을 넣습니다. 업데이트는 저장소의 파일을 덮어쓴 뒤 실리태번에서 확장 업데이트 후 새로고침합니다. 특히 새 `memory-engine.js`를 빠뜨리면 확장이 시작되지 않습니다.

수동 설치는 `SillyTavern/data/<사용자>/extensions/third-party/memorybean/` 안에 manifest.json과 나머지 파일이 바로 놓이도록 압축 해제합니다.

Jev는 실리태번 기본 채팅 API를 통한 전달을 먼저 시도하고, 지원되지 않으면 직접 연결·내장 프록시를 순서대로 시도합니다. 키는 현재 브라우저 로컬 저장소에 저장됩니다.

## 확인한 범위

자동 정리, 약속의 완료·취소 조건, 상태 갱신, 원문 근거 검사, 보호된 기억, 리롤·삭제 되돌리기, 별도 프로필, 번역, 기존 검수 흐름을 모의 환경의 자동 테스트로 확인했습니다. 실제 SillyTavern 및 유료 API 계정에 연결한 통합 테스트는 이 환경에서 실행하지 못했습니다. 먼저 짧은 채팅에서 기억이 자동으로 추가되는지 확인하세요. 자동 기억은 캐릭터별 1:1 채팅을 지원하며 그룹 채팅은 지원하지 않습니다.
