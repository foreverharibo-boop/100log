# 💯 100LOG 1.8.2

최근 100개의 사용자·AI 메시지를 기준으로 새 답변의 연속성 오류를 공개 전에 차단하는 SillyTavern 확장입니다. 장기 설정은 로어북과 요약 확장에 맡기고, 100LOG는 약속·사건·지식 차이·거짓말·오해·정정사항을 검수 규칙으로 관리합니다.

## 핵심 기능

- 현재 채팅의 최근 **100개 보이는 메시지**만 분석합니다. 시스템·숨김 메시지는 100개 계산에서 제외합니다.
- 검수 규칙은 캐릭터 카드의 고유 UUID별로 저장합니다. 같은 캐릭터로 만든 여러 채팅은 규칙을 공유하고, 표시 이름이 같은 다른 캐릭터의 규칙은 섞이지 않습니다.
- 최근 100개 수집 위치와 되돌리기 기록은 채팅별로 따로 관리합니다. 한 채팅을 처음부터 재수집해도 같은 캐릭터의 다른 채팅에서 모은 규칙은 지우지 않습니다.
- 범위를 벗어난 자동 규칙은 다음 갱신에서 삭제합니다. 직접 추가하거나 자동 변경 잠금한 규칙은 유지합니다.
- 새 AI 답변이 올 때마다 기본적으로 규칙을 자동 갱신합니다. 1 이상의 원하는 답변 수를 직접 입력해 주기를 정할 수 있습니다.
- 규칙 수집 강도를 `세세하게 / 균형 / 의미 중심`으로 선택할 수 있습니다. 기본값은 `균형`입니다.
- 날짜·시간·장소가 정해진 미래 일정, 함께 하기로 합의한 행동, 명시적인 약속·거절·취소·이행, 사용자 정정, 비밀과 지식 차이는 수집 강도와 관계없이 반드시 수집 대상으로 요청합니다.
- 미해결 약속은 매번 새 대화와 다시 대조합니다. `약속대로`라는 표현이 없어도 약속한 인물들이 약속한 장소에 도착했거나 약속한 행동을 실제로 하는 장면이 확인되면 완료 처리합니다. 단순히 시간이 지났거나 비슷한 분위기만 나온 경우에는 완료하지 않습니다.
- 약속 이행을 판정할 때 새 분석 구간 바로 앞의 보이는 메시지를 최대 8개까지 함께 참고해, 장소에 도착한 뒤 자연스럽게 이어지는 장면도 놓치지 않도록 했습니다.
- 짧은 시간에 분석된 메시지 8개 이상이 한꺼번에 하이드되면 `요약 압축`으로 자동 인식합니다. 하이드 이벤트를 0.9초 동안 모아 한 번만 처리하므로, 요약 확장이 수십 개 메시지를 숨겨도 매번 규칙을 되돌리지 않습니다.
- 요약 압축 시 미해결 약속·계획, 비밀과 인물별 지식, 계속 유효한 거짓말·오해·정정사항, 중요한 관계 변화는 `요약 이월` 규칙으로 유지합니다. 완료된 짧은 사건과 일반 장면 규칙은 장기 요약에 맡기고 정리합니다.
- 메시지 한두 개를 하이드하거나 편집한 경우에는 요약으로 오인하지 않고, 해당 변경 지점부터 기존 방식대로 다시 확인합니다.
- 날짜·시간·날씨·장소·복장·자세·위치·착용품·소지품은 저장하지 않습니다. 이 정보는 또또SFW가 담당합니다.
- 별도 연결 프로필로 규칙을 정리할 수 있어 메인 RP API와 분리할 수 있습니다.
- `새 대화만 갱신`은 현재 규칙을 유지한 채 아직 정리하지 않은 대화만 반영하고, `최근 100개 처음부터 재수집`은 자동 규칙을 비운 뒤 최근 범위를 다시 만듭니다.
- 새 규칙은 한 사건·주장·약속 단위로 나눕니다. JEV가 서로 다른 지식 경계를 한 문장에 합친 복합 규칙을 발견하면 저장을 거부하고, 정리용 AI가 원문 근거에 맞춰 다시 분리한 결과를 재검증합니다.
- JEV 키가 있으면 새 규칙 자체를 원문과 대조합니다. 왜곡·추측·날조·등장하지 않은 인물·의도를 완료된 사건처럼 바꾼 규칙은 저장하지 않습니다.
- 같은 JEV 요청에서 인물별 `알고 있음/아직 모름`도 검증합니다. 이름이 언급됐거나 일부 내용만 안다는 이유로 전체 사실을 안다고 처리하지 않습니다.
- 활성 규칙은 최대 40개입니다. 자동 청소를 시작할 규칙 수는 5~40개 사이에서 직접 정할 수 있으며 기본값은 20개입니다.
- 설정한 개수 이상이면 정리용 AI가 자동 청소안을 제안하고, JEV가 원문과 기존 규칙을 다시 확인해 승인한 병합·종료만 적용합니다.
- 충돌 규칙은 JEV가 새 규칙의 명확한 대체, 실제 양립 가능, 판단 불가로 나눕니다. 대체가 분명하면 옛 규칙을 보관하고, 양립하면 충돌 표시를 해제하며, 판단할 수 없으면 둘 다 유지한 채 `확인 필요`로 남깁니다.
- 직접 추가하거나 자동 변경 잠금한 규칙은 자동 청소가 변경하지 않습니다. 완료·취소는 최근 원문의 정확한 근거가 있을 때만 처리합니다.
- **100LOG 사용**을 켜면 메인 AI 답변을 숨은 초안으로 생성하고 JEV가 현재 규칙과 한 번에 비교합니다.
- 새 스와이프도 별도 설정 없이 사용자에게 표시하기 전에 같은 검수·재작성 과정을 거칩니다.
- 실리태번의 **재생성**과 `Ctrl+Enter`로 만든 답변도 일반 답변과 똑같이 공개 전 검수를 거칩니다.
- 충돌이 발견된 경우에만 메인 AI에 한 번 재작성을 요청하고, 재검수를 통과한 답변만 채팅에 표시합니다.
- 재검수 후에도 충돌이 남아 답변을 숨긴 경우처럼 사용자 확인이 꼭 필요한 최종 실패만 오류 토스트로 알립니다. 평상시 작업 안내 문구는 화면에 표시하지 않습니다.
- 설정 화면의 `최근 작업`에 마지막 수집 또는 공개 전 검수 결과를 한 줄로 남깁니다. 분석한 답변 수, 추가·갱신·종료된 규칙 수, JEV 통과 수, 주입·검수·수정 결과를 확인할 수 있습니다.
- 대량 하이드가 처리되면 `최근 작업`에서 하이드된 메시지 수, 이월된 중요 규칙 수, 정리된 최근 장면 규칙 수를 확인할 수 있습니다.
- 자동 갱신 주기를 50 이상으로 입력하면 오래된 메시지가 정리 전에 최근 100개 범위에서 빠질 수 있다는 경고를 표시합니다.

## 100LOG가 관리하는 규칙

- 아직 실행되지 않은 약속·계획·목표
- 해결되지 않은 사건·질문·갈등
- 누가 무엇을 알게 되었거나 아직 모르는지
- 거짓말·오해·숨긴 사실
- 사용자가 직접 정정한 내용
- 다음 답변의 인과관계에 필요한 최근 사건
- 최근 대화에서 발생한 중요한 관계 변화

평범한 대사를 전부 요약하거나 장기 세계관을 복제하지 않습니다. 계획을 완료된 사건으로 바꾸지 않으며, 약속은 실제 이행 또는 명시적인 취소가 확인될 때만 종료합니다.

## 처음 사용하기

1. `100LOG → 설정`에서 **최근 100개 규칙 정리용 프로필**을 선택합니다. 비워두면 현재 메인 API를 사용합니다.
2. JEV API 키를 저장하고 연결을 확인합니다.
3. 상단의 **100LOG 사용**을 켜고 평소처럼 RP합니다. 최근 규칙 관리와 일반·재생성·스와이프 공개 전 검수가 함께 작동합니다.
4. 자동 규칙을 버리고 현재 범위를 다시 만들고 싶으면 **최근 100개 처음부터 재수집**을 누릅니다. 직접 추가하거나 자동 변경 잠금한 규칙은 유지됩니다.

## 동작 흐름

1. 최근 100개 범위에서 새로 추가된 메시지를 규칙 정리용 AI가 분석합니다.
2. 정리용 AI가 제안한 약속·오해·거짓말·비밀·정정사항을 JEV가 원문과 대조하고, 근거가 확인된 규칙만 캐릭터 UUID 저장소에 저장합니다.
3. 현재 규칙이 사용자가 정한 자동 청소 시작 개수 이상이면 정리용 AI가 중복·종료·충돌 청소안을 만들고, JEV가 승인한 작업만 적용합니다.
4. 일반 답변·재생성 답변·스와이프 답변을 바로 공개하지 않고 사용자에게 보이지 않는 초안으로 생성합니다.
5. JEV가 초안 전체를 현재 연속성 규칙 전체와 한 번에 비교합니다.
6. 문제가 없으면 초안을 바로 채팅에 표시합니다.
7. 문제가 있으면 충돌한 규칙과 근거를 담은 재작성 지시를 메인 AI에 한 번 전달합니다.
8. 수정 답변을 다시 검사하고, 통과한 경우에만 채팅에 표시합니다.
9. 연결 오류나 재검수 실패가 발생하면 잘못된 초안을 표시하지 않습니다.

정상 답변에서는 **메인 AI 숨은 초안 1회 + JEV 통합 검수 1회**가 실행됩니다. 오류가 발견된 경우에만 **메인 AI 재작성 1회 + JEV 재검수 1회**가 추가됩니다.

규칙 자동 청소는 현재 규칙이 설정한 개수 이상이고 이전 청소 뒤 규칙 목록이 바뀐 경우에만 수집용 AI를 1회 추가 호출합니다. 목록이 그대로라면 같은 청소를 반복 호출하지 않습니다.

## 화면

- **검수 규칙**: 현재 최근 100개 범위에서 답변 검사에 사용하는 규칙입니다. 수정·자동 변경 잠금·잠시 끄기·삭제가 가능합니다.
- 규칙의 **인물별 지식** 표시는 이름·상태 부분을 누르면 `알고 있음/아직 모름`이 즉시 전환되고, 옆의 `×`는 해당 인물 기록만 삭제합니다.
- **지난 규칙**: 최근 범위 안에서 완료·취소·갱신된 규칙입니다. 범위를 벗어나면 자동 기록은 삭제됩니다.
- **설정**: 분석·번역 프로필, 수집 강도, 자동 갱신 주기, 자동 청소 시작 개수, 최근 100개 재분석, JEV 연결을 관리합니다.
- **한국어 번역**: AI 연결 프로필 또는 Google 번역을 선택해 저장된 규칙과 출처를 번역하며, RP 채팅 원문은 변경하지 않습니다.

메인 설정창과 마법봉 메뉴에서 모두 열 수 있습니다. 마법봉에서는 가운데 고정 팝업으로 표시됩니다. 색상은 실리태번 테마를 따르며 글씨 그림자를 사용하지 않습니다.

## 이전 버전에서 업데이트

기존 사실·규칙과 JEV 키는 유지됩니다.

같은 GitHub 저장소를 덮어써 업데이트하면 기존 메모리콩의 설정과 채팅별 기록도 각 채팅을 처음 열 때 해당 캐릭터 UUID 저장소로 복사합니다. 복사 뒤에는 같은 캐릭터의 모든 채팅에서 함께 사용합니다. 설치 폴더 이름이 예전 `memorybean`으로 남아 있어도 작동에는 문제가 없습니다.

## 설치

서버 플러그인은 필요 없습니다. GitHub 저장소 최상위에 다음 7개 파일을 올립니다.

- manifest.json
- index.js
- core.js
- memory-engine.js
- settings.html
- style.css
- README.md

실리태번의 `확장 → 확장 설치`에는 ZIP 주소가 아니라 GitHub 저장소 주소를 입력합니다. 수동 설치 시에는 `data/<사용자>/extensions/third-party/100log/` 안에 위 파일들이 바로 놓이도록 압축을 풉니다.

## 제한 사항

- 캐릭터별 1:1 채팅을 지원하며 그룹 채팅은 지원하지 않습니다. 같은 캐릭터의 여러 채팅은 하나의 연속된 세계선으로 보고 규칙을 공유합니다.
- 공개 전 검수는 일반 생성·재생성·스와이프에 항상 적용됩니다. 이어쓰기·유저 역할 생성에는 적용하지 않습니다.
- 해당 캐릭터에 활성 검수 규칙이 하나도 없으면 답변을 가로채지 않습니다.
- 숨은 초안은 일반 생성과 프롬프트 구성이 완전히 같지 않을 수 있습니다.
- 다른 확장의 프롬프트를 읽거나 복원하지 않습니다.
- 실제 SillyTavern 및 유료 API 계정 연결은 사용 환경에 따라 달라질 수 있으므로 먼저 짧은 채팅에서 확인하세요.
