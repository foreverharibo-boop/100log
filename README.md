# 💯 100LOG 1.0.0

최근 100개의 사용자·AI 메시지만 읽어 RP의 단기 연속성을 관리하는 SillyTavern 확장입니다. 장기 설정은 로어북과 요약 확장에 맡기고, 100LOG는 지금 답변에서 놓치기 쉬운 약속·사건·지식 차이·거짓말·오해·정정사항만 관리합니다.

## 핵심 기능

- 현재 채팅의 최근 **100개 보이는 메시지**만 분석합니다. 시스템·숨김 메시지는 100개 계산에서 제외합니다.
- 범위를 벗어난 자동 기억은 다음 갱신에서 삭제합니다. 직접 추가하거나 보호한 기억은 유지합니다.
- 새 AI 답변이 올 때마다 기본적으로 기억을 자동 갱신합니다. 1·2·3·5개 답변마다로 변경할 수 있습니다.
- 다음 RP 생성 직전에 관련 기억을 `<LOG100_CONTEXT>`로 전달합니다.
- 날짜·시간·날씨·장소·복장·자세·위치·착용품·소지품은 저장하지 않습니다. 이 정보는 또또SFW가 담당합니다.
- 별도 연결 프로필로 기억을 정리할 수 있어 메인 RP API와 분리할 수 있습니다.
- 선택형 **Jev 엄격 검수**는 답변을 숨은 초안으로 생성하고, 기억 충돌을 발견하면 메인 AI에 한 번 재작성을 요청한 뒤 통과한 답변만 표시합니다.

## 100LOG가 기억하는 것

- 아직 실행되지 않은 약속·계획·목표
- 해결되지 않은 사건·질문·갈등
- 누가 무엇을 알게 되었거나 아직 모르는지
- 거짓말·오해·숨긴 사실
- 사용자가 직접 정정한 내용
- 다음 답변의 인과관계에 필요한 최근 사건
- 최근 대화에서 발생한 중요한 관계 변화

평범한 대사를 전부 요약하거나 장기 세계관을 복제하지 않습니다. 계획을 완료된 사건으로 바꾸지 않으며, 약속은 실제 이행 또는 명시적인 취소가 확인될 때만 정리합니다.

## 처음 사용하기

1. `100LOG → 설정`에서 **최근 100개 기억 정리용 프로필**을 선택합니다. 비워두면 현재 메인 API를 사용합니다.
2. 상단의 **100LOG 사용**을 켜고 평소처럼 RP합니다. 새 채팅에서는 최근 100개 범위부터 자동 분석합니다.
3. 기존 기억을 버리고 현재 범위를 다시 만들고 싶으면 **최근 100개 다시 분석**을 누릅니다. 직접 추가하거나 보호한 기억은 유지됩니다.
4. 기억 충돌을 실제 답변 공개 전에 검사하려면 Jev 키를 저장한 뒤 **엄격 검수 사용**을 켭니다.

## 동작 흐름

### 기본 모드

1. 최근 100개 범위에서 새로 추가된 메시지를 기억 정리용 AI가 분석합니다.
2. 100LOG가 유효한 기억을 채팅 메타데이터에 저장합니다.
3. 다음 답변 생성 직전에 관련 기억을 메인 AI에게 전달합니다.
4. 메시지가 100개 범위를 벗어나면 그 메시지에서 나온 자동 기억도 제거합니다.

### Jev 엄격 검수

1. 일반 답변 생성을 보류합니다.
2. 메인 AI가 사용자에게 보이지 않는 초안을 만듭니다.
3. Jev가 초안과 최근 기억을 비교해 직접 모순과 명시적인 지식 누출을 검사합니다.
4. 문제가 있으면 충돌한 부분과 근거를 담은 재작성 지시를 메인 AI에 한 번 전달합니다.
5. 수정 답변을 다시 검사하고, 통과한 경우에만 채팅에 표시합니다.
6. 연결 오류나 재검수 실패가 발생하면 잘못된 초안을 표시하지 않습니다.

엄격 검수는 추가 Jev 호출을 사용하며, 충돌 시 메인 AI 재작성 호출도 한 번 추가됩니다. AI 판정이므로 모든 모순을 보장해서 잡아내는 기능은 아닙니다.

## 화면

- **최근 기억**: 현재 최근 100개 범위에서 사용하는 기억. 수정·보호·잠시 끄기·삭제가 가능합니다.
- **정리된 기록**: 최근 범위 안에서 완료·취소·갱신된 기록입니다. 범위를 벗어나면 자동 기록은 삭제됩니다.
- **설정**: 분석·번역 프로필, 갱신 주기, 전달 개수, 최근 100개 재분석, Jev 엄격 검수를 관리합니다.
- **한국어 번역**: 저장된 기억과 출처를 번역합니다. RP 채팅 원문은 변경하지 않습니다.

메인 설정창과 마법봉 메뉴에서 모두 열 수 있습니다. 마법봉에서는 화면 전체를 덮는 페이지가 아니라 가운데 고정 팝업으로 표시됩니다. 색상은 실리태번 테마를 따르며 글씨 그림자를 사용하지 않습니다.

## 기존 메모리콩에서 업데이트

같은 GitHub 저장소를 덮어써 업데이트하면 기존 메모리콩의 설정과 채팅별 기억을 처음 한 번 100LOG로 복사합니다. 복사된 자동 기억 중 최근 100개 범위 밖의 항목은 제거됩니다. 기존 Jev 키도 새 키 저장소가 비어 있을 때 이어서 읽습니다.

확장 표시 이름과 내부 주입 이름은 100LOG로 변경되었습니다. 설치 폴더 이름이 예전 `memorybean`으로 남아 있어도 작동에는 문제가 없습니다.

## 설치

서버 플러그인은 필요 없습니다. GitHub 저장소 최상위에 다음 7개 파일을 올립니다.

- manifest.json
- index.js
- core.js
- memory-engine.js
- settings.html
- style.css
- README.md

실리태번의 `확장 → 확장 설치`에는 ZIP 주소가 아니라 GitHub 저장소 주소를 입력합니다. 수동 설치 시에는 `data/<사용자>/extensions/third-party/100log/` 안에 위 파일들이 바로 놓이도록 압축을 풉니다.

## 제한 사항

- 캐릭터별 1:1 채팅을 지원하며 그룹 채팅은 지원하지 않습니다.
- 엄격 검수는 일반 생성만 대상으로 합니다. 스와이프·이어쓰기·유저 역할 생성은 검수하지 않습니다.
- 숨은 초안은 일반 생성과 프롬프트 구성이 완전히 같지 않을 수 있습니다.
- 다른 확장의 프롬프트를 읽거나 복원하지 않습니다.
- 실제 SillyTavern 및 유료 API 계정 연결은 사용 환경에 따라 달라질 수 있으므로 먼저 짧은 채팅에서 확인하세요.
