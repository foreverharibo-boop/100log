# 💯 100LOG 1.5.8

최근 100개의 사용자·AI 메시지를 기준으로 새 답변의 연속성 오류를 공개 전에 차단하는 SillyTavern 확장입니다. 장기 설정은 로어북과 요약 확장에 맡기고, 100LOG는 약속·사건·지식 차이·거짓말·오해·정정사항을 검수 규칙으로 관리합니다.

## 핵심 기능

- 현재 채팅의 최근 **100개 보이는 메시지**만 분석합니다. 시스템·숨김 메시지는 100개 계산에서 제외합니다.
- 범위를 벗어난 자동 규칙은 다음 갱신에서 삭제합니다. 직접 추가하거나 자동 변경 잠금한 규칙은 유지합니다.
- 새 AI 답변이 올 때마다 기본적으로 규칙을 자동 갱신합니다. 1 이상의 원하는 답변 수를 직접 입력해 주기를 정할 수 있습니다.
- 날짜·시간·날씨·장소·복장·자세·위치·착용품·소지품은 저장하지 않습니다. 이 정보는 또또SFW가 담당합니다.
- 별도 연결 프로필로 규칙을 정리할 수 있어 메인 RP API와 분리할 수 있습니다.
- `새 대화만 갱신`은 현재 규칙을 유지한 채 아직 정리하지 않은 대화만 반영하고, `최근 100개 처음부터 재수집`은 자동 규칙을 비운 뒤 최근 범위를 다시 만듭니다.
- 새 규칙은 한 사건·주장·약속 단위로 나눕니다. JEV가 서로 다른 지식 경계를 한 문장에 합친 복합 규칙을 발견하면 저장을 거부하고, 정리용 AI가 원문 근거에 맞춰 다시 분리한 결과를 재검증합니다.
- JEV 키가 있으면 새 규칙 자체를 원문과 대조합니다. 왜곡·추측·날조·등장하지 않은 인물·의도를 완료된 사건처럼 바꾼 규칙은 저장하지 않습니다.
- 같은 JEV 요청에서 인물별 `알고 있음/아직 모름`도 검증합니다. 이름이 언급됐거나 일부 내용만 안다는 이유로 전체 사실을 안다고 처리하지 않습니다.
- 현재 규칙이 20개 이상이면 정리용 AI가 자동 청소안을 제안하고, JEV가 원문과 기존 규칙을 다시 확인해 승인한 병합·종료만 적용합니다.
- 충돌 규칙은 JEV가 새 규칙의 명확한 대체, 실제 양립 가능, 판단 불가로 나눕니다. 대체가 분명하면 옛 규칙을 보관하고, 양립하면 충돌 표시를 해제하며, 판단할 수 없으면 둘 다 유지한 채 `확인 필요`로 남깁니다.
- 직접 추가하거나 자동 변경 잠금한 규칙은 자동 청소가 변경하지 않습니다. 완료·취소는 최근 원문의 정확한 근거가 있을 때만 처리합니다.
- **공개 전 엄격 검수**를 켜면 메인 AI 답변을 숨은 초안으로 생성하고 JEV가 현재 규칙과 한 번에 비교합니다.
- **스와이프 답변도 엄격 검수**를 켜면 새 스와이프도 사용자에게 표시하기 전에 같은 검수·재작성 과정을 거칩니다.
- 실리태번의 **재생성**과 `Ctrl+Enter`로 만든 답변도 일반 답변과 똑같이 공개 전 엄격 검수를 거칩니다.
- 충돌이 발견된 경우에만 메인 AI에 한 번 재작성을 요청하고, 재검수를 통과한 답변만 채팅에 표시합니다.
- 재검수 후에도 충돌이 남아 답변을 숨긴 경우처럼 사용자 확인이 꼭 필요한 최종 실패만 오류 토스트로 알립니다. 평상시 작업 안내 문구는 화면에 표시하지 않습니다.
- 설정 화면의 `최근 작업`에 마지막 수집 또는 엄격 검수 결과를 한 줄로 남깁니다. 분석한 답변 수, 추가·갱신·종료된 규칙 수, JEV 통과 수, 주입·검수·수정 결과를 확인할 수 있습니다.
- 자동 갱신 주기를 50 이상으로 입력하면 오래된 메시지가 정리 전에 최근 100개 범위에서 빠질 수 있다는 경고를 표시합니다.

## 100LOG가 관리하는 규칙

- 아직 실행되지 않은 약속·계획·목표
- 해결되지 않은 사건·질문·갈등
- 누가 무엇을 알게 되었거나 아직 모르는지
- 거짓말·오해·숨긴 사실
- 사용자가 직접 정정한 내용
- 다음 답변의 인과관계에 필요한 최근 사건
- 최근 대화에서 발생한 중요한 관계 변화

평범한 대사를 전부 요약하거나 장기 세계관을 복제하지 않습니다. 계획을 완료된 사건으로 바꾸지 않으며, 약속은 실제 이행 또는 명시적인 취소가 확인될 때만 종료합니다.

## 처음 사용하기

1. `100LOG → 설정`에서 **최근 100개 규칙 정리용 프로필**을 선택합니다. 비워두면 현재 메인 API를 사용합니다.
2. 상단의 **100LOG 사용**을 켜고 평소처럼 RP합니다. 새 채팅에서는 최근 100개 범위부터 자동 분석합니다.
3. JEV API 키를 저장하고 연결을 확인합니다.
4. **답변 공개 전 엄격 검수 · 자동 재작성**을 켭니다.
5. 자동 규칙을 버리고 현재 범위를 다시 만들고 싶으면 **최근 100개 처음부터 재수집**을 누릅니다. 직접 추가하거나 자동 변경 잠금한 규칙은 유지됩니다.

## 동작 흐름

1. 최근 100개 범위에서 새로 추가된 메시지를 규칙 정리용 AI가 분석합니다.
2. 정리용 AI가 제안한 약속·오해·거짓말·비밀·정정사항을 JEV가 원문과 대조하고, 근거가 확인된 규칙만 채팅 메타데이터에 저장합니다.
3. 현재 규칙이 20개 이상이면 정리용 AI가 중복·종료·충돌 청소안을 만들고, JEV가 승인한 작업만 적용합니다.
4. 일반 답변·재생성 답변 또는 설정에서 허용한 스와이프 답변을 바로 공개하지 않고 사용자에게 보이지 않는 초안으로 생성합니다.
5. JEV가 초안 전체를 현재 연속성 규칙 전체와 한 번에 비교합니다.
6. 문제가 없으면 초안을 바로 채팅에 표시합니다.
7. 문제가 있으면 충돌한 규칙과 근거를 담은 재작성 지시를 메인 AI에 한 번 전달합니다.
8. 수정 답변을 다시 검사하고, 통과한 경우에만 채팅에 표시합니다.
9. 연결 오류나 재검수 실패가 발생하면 잘못된 초안을 표시하지 않습니다.

정상 답변에서는 **메인 AI 숨은 초안 1회 + JEV 통합 검수 1회**가 실행됩니다. 오류가 발견된 경우에만 **메인 AI 재작성 1회 + JEV 재검수 1회**가 추가됩니다.

규칙 자동 청소는 현재 규칙이 20개 이상이고 이전 청소 뒤 규칙 목록이 바뀐 경우에만 수집용 AI를 1회 추가 호출합니다. 목록이 그대로라면 같은 청소를 반복 호출하지 않습니다.

## 화면

- **검수 규칙**: 현재 최근 100개 범위에서 답변 검사에 사용하는 규칙입니다. 수정·자동 변경 잠금·잠시 끄기·삭제가 가능합니다.
- 규칙의 **인물별 지식** 표시는 이름·상태 부분을 누르면 `알고 있음/아직 모름`이 즉시 전환되고, 옆의 `×`는 해당 인물 기록만 삭제합니다.
- **지난 규칙**: 최근 범위 안에서 완료·취소·갱신된 규칙입니다. 범위를 벗어나면 자동 기록은 삭제됩니다.
- **설정**: 분석·번역 프로필, 자동 갱신 주기, 최근 100개 재분석, JEV 공개 전 엄격 검수를 관리합니다.
- **한국어 번역**: AI 연결 프로필 또는 Google 번역을 선택해 저장된 규칙과 출처를 번역하며, RP 채팅 원문은 변경하지 않습니다.

메인 설정창과 마법봉 메뉴에서 모두 열 수 있습니다. 마법봉에서는 가운데 고정 팝업으로 표시됩니다. 색상은 실리태번 테마를 따르며 글씨 그림자를 사용하지 않습니다.

## 이전 버전에서 업데이트

기존 사실·규칙과 JEV 키는 유지됩니다.

같은 GitHub 저장소를 덮어써 업데이트하면 기존 메모리콩의 설정과 채팅별 기록도 처음 한 번 100LOG로 복사합니다. 설치 폴더 이름이 예전 `memorybean`으로 남아 있어도 작동에는 문제가 없습니다.

## 설치

서버 플러그인은 필요 없습니다. GitHub 저장소 최상위에 다음 7개 파일을 올립니다.

- manifest.json
- index.js
- core.js
- memory-engine.js
- settings.html
- style.css
- README.md

실리태번의 `확장 → 확장 설치`에는 ZIP 주소가 아니라 GitHub 저장소 주소를 입력합니다. 수동 설치 시에는 `data/<사용자>/extensions/third-party/100log/` 안에 위 파일들이 바로 놓이도록 압축을 풉니다.

## 제한 사항

- 캐릭터별 1:1 채팅을 지원하며 그룹 채팅은 지원하지 않습니다.
- 공개 전 엄격 검수는 일반 생성과 재생성에 적용되며, 스와이프는 별도 선택 기능을 켰을 때 적용됩니다. 이어쓰기·유저 역할 생성에는 적용하지 않습니다.
- 활성 검수 규칙이 하나도 없는 채팅에서는 답변을 가로채지 않습니다.
- 숨은 초안은 일반 생성과 프롬프트 구성이 완전히 같지 않을 수 있습니다.
- 다른 확장의 프롬프트를 읽거나 복원하지 않습니다.
- 실제 SillyTavern 및 유료 API 계정 연결은 사용 환경에 따라 달라질 수 있으므로 먼저 짧은 채팅에서 확인하세요.
