# 🌱 메모리콩 0.1.1

SillyTavern RP 답변을 보여주기 전에 승인된 이야기 사실과 충돌하는지 확인하는 확장입니다.

## 설치

**SillyTavern의 `확장 설치` 입력창은 Git 저장소 URL을 받습니다. ZIP 링크를 입력하면 설치되지 않습니다.** 서버 플러그인은 필요하지 않습니다.

### GitHub에서 설치

1. 새 GitHub 저장소를 만들고, 이 ZIP을 **압축 해제**합니다. ZIP 파일 자체를 업로드하지 않습니다.
2. 압축을 풀어 나온 파일들을 **저장소 최상위**에 올립니다. GitHub 저장소를 열었을 때 `manifest.json`, `index.js`, `core.js`, `settings.html`, `style.css`가 바로 보여야 합니다. 별도 `memorybean/`이나 `server-plugin/` 폴더는 올리지 않습니다.
3. SillyTavern `확장 → 확장 설치`에 GitHub 저장소 주소(`https://github.com/사용자명/저장소명`)를 입력합니다.
4. 설치 후 `🌱 메모리콩`에서 TypeSafe AI API 키를 입력하고 `연결 확인`을 누릅니다.

이미 이전 파일을 GitHub에 올렸다면 저장소 최상위의 여섯 파일을 새 파일로 덮어쓴 뒤 SillyTavern에서 확장을 업데이트하고 페이지를 새로고침하세요. 이전 압축의 `server-plugin/`, `tests/`, `package.json`은 올리지 않아도 됩니다. 예전 버전의 설정 화면은 GitHub 저장소 폴더명이 `memorybean`이 아닐 때 보이지 않을 수 있으며, 0.1.1에서 설치된 파일의 위치를 직접 찾아 읽도록 수정했습니다.

### ZIP 수동 설치

SillyTavern의 `data/<사용자>/extensions/third-party/memorybean/` 폴더에 ZIP을 압축 해제합니다. 그 안에 `manifest.json`이 바로 있어야 합니다.

Jev API 요청은 브라우저에서 `https://api.typesafe.ai/v1/systemone`으로 직접 전송합니다. 키는 **현재 브라우저의 로컬 저장소**에 저장되므로 같은 SillyTavern 페이지를 열 수 있는 브라우저 스크립트에도 노출될 수 있습니다. 공유 기기에서는 사용 후 `키 삭제`를 누르세요. 브라우저에서 CORS 요청이 차단된다면 `연결 확인`에 오류가 표시됩니다. 그 환경에서는 직접 연결 방식으로 사용할 수 없습니다.

## 사용

1. 캐릭터와 채팅을 선택합니다. 그룹 채팅은 첫 버전에서 지원하지 않습니다.
2. `히스토리에서 후보 찾기`를 눌러 대화 40개씩 후보를 모으고, 원문을 확인한 후 `승인`합니다. 반복해서 누르면 다음 40개를 읽습니다. 직접 사실을 적어 추가할 수도 있습니다.
3. `자동 검수 켜기`를 켭니다. 승인된 사실이 없다면 일반 생성이 그대로 진행됩니다.
4. 사용자 메시지를 평소처럼 보냅니다. 일반 생성만 가로채며, 숨은 초안 → Jev 검수 → 필요시 수정/재검수 → 최종 표시 순서로 처리합니다.

메모리콩이 활성화되면 일반 생성은 먼저 중단합니다. 검수 오류, API 오류, 수정 실패, 채팅 전환이 일어나면 숨은 답변은 표시하지 않고 설정창에 사유를 적습니다. 원할 때 자동 검수를 끄고 일반 생성 버튼을 눌러 다시 시도할 수 있습니다. 최대 한 번만 수정하므로 무한 생성하지 않습니다.

## 첫 버전의 범위와 확인할 점

- 원본 RP 모델을 `generateQuietPrompt()`로 호출합니다. 이 호출은 채팅의 캐릭터 정보를 유지하며 출력을 화면에 표시하지 않지만, 일반 생성과 프롬프트가 완전히 동일하지는 않을 수 있습니다. 메모리콩은 다른 확장의 설정이나 주입문을 읽거나 복원하지 않습니다. 다른 확장이 일반 생성에만 적용하는 주입은 숨은 생성에 적용되지 않을 수 있습니다.
- 자동 검수는 **일반 생성**만 적용합니다. 스와이프, 이어쓰기, 재생성, 그룹 채팅은 범위 밖입니다.
- 오래된 채팅에서 사실을 추출할 때 AI가 후보를 잘못 뽑을 수 있습니다. 승인하기 전에 출처를 확인해야 합니다. 장면이 바뀌면 임시 사실을 꺼 주세요.
- Jev는 사실과 문단 사이의 모순을 확률적으로 판정합니다. 세계관의 참거짓 전체를 증명하거나 모든 잘못을 보장해 잡아내지는 못합니다. 모델 오류로 승인된 사실과 충돌하는 답변이 남을 수 있습니다.
- TypeSafe 공식 SDK는 브라우저 직접 사용을 지원하는 옵션을 제공하지만 기본값은 꺼져 있고 키가 페이지에 노출된다고 안내합니다. 실제 브라우저의 CORS 허용 여부는 설치 후 `연결 확인`으로 검증해야 합니다.
- 실제 SillyTavern 및 TypeSafe API 계정에 연결한 통합 테스트는 이 패키지를 만드는 환경에서 실행하지 못했습니다. 설치 후 **짧은 테스트 채팅**으로 연결과 답변 표시 흐름을 확인해 주세요.
