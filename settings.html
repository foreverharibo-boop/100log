규칙 수집

RP용 API를 바꾸지 않고, 선택한 프로필로 규칙을 정리해요.

약속·비밀·정정은 모든 강도에서 수집해요. 세세하게는 작은 부탁·제안·취향·경험·변화까지 넓게 모으며, 미확정 계획은 미확정으로 기록해요. 규칙이 많아지면 검수량도 늘어요. 갱신 주기는 AI 답변 수 기준이에요.

갱신 주기가 50 이상이면 정리되기 전에 오래된 메시지가 최근 100개 범위에서 빠질 수 있어요.

5~40개부터 정리 AI가 청소해요. 원문 인용·잠금·병합 조건을 코드로 검사한 뒤 적용하며 직접 추가·잠금한 규칙은 유지해요.

집중해서 수집할 항목

여러 개를 선택할 수 있어요. 선택한 항목은 작은 내용도 더 주의해서 수집해요. 선택하지 않은 항목도 기존 수집 기준에 따라 모아요.

입력·선택하면 자동 저장돼요. 같은 캐릭터의 채팅끼리 공유하며 다음 수집부터 적용돼요. 기존 기억은 자동으로 다시 수집하지 않아요. 아무것도 선택하거나 적지 않으면 기존 방식으로 작동해요.

수집에서 제외된 항목

이 채팅의 최근 수집 1회에서 코드 검사로 빠진 제안만 최대 64개 표시해요. AI가 처음부터 제안하지 않은 내용이나 자동 청소 내역은 포함되지 않아요. 내용·인용은 이 설정에만 보관하며 오류 기록에는 넣지 않아요.

기억 수집과 인물별 지식 정리는 정리 AI가 맡아요. JEV는 새 답변을 기억·관련 원문과 비교하며, 자동 기억보다 원문을 우선해요.

기억 관리

자동으로 만든 기존 규칙을 비우고 최근 100개를 처음부터 다시 수집해요. 직접 추가하거나 자동 변경 잠금한 규칙은 유지해요.

장면 한정 규칙은 현재 장면이나 가까운 몇 턴에만 필요한 사실이에요. 모두 끄기는 삭제하지 않고 검사에서 제외하며, 각 규칙의 ‘다시 켜기’로 복구할 수 있어요.

마지막 오류

마지막 오류 1건만 보관해요. 실패 단계·소요 시간·오류 전달 경로와 확인 가능한 HTTP 코드·호출 위치를 함께 남겨요. 정상 작업은 저장하지 않으며 추가 API 호출과 원문·인물명·키 기록은 없어요.

문제가 생기면 ‘오류 복사’로 전달해 주세요. 새로고침해도 마지막 오류는 유지돼요. 서버 내부나 다른 확장 오류 전체를 기록하는 기능은 아니에요.
