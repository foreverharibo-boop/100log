최근 100개 연속성 검사

같은 캐릭터의 모든 채팅에서 약속·오해·비밀·정정사항을 함께 관리해요.

한국어 번역

저장된 기억과 출처를 선택한 방식으로 번역해요. 원문과 RP 채팅은 바꾸지 않아요.

현재 규칙

기존 규칙은 유지하고 아직 정리하지 않은 새 대화만 이어서 반영해요.

직접 추가 · 기존 규칙 갱신

직접 쓴 규칙은 자동 변경 잠금 상태로 저장해요. AI가 관리하게 하려면 잠금을 해제하세요.

완료된 일 · 바뀌기 전 상태

현재 답변 검사에는 사용하지 않아요. 잘못 종료된 규칙은 복원할 수 있어요.

이전 버전의 미승인 후보

예전 후보는 그대로 보관했어요. 새 자동 기억은 승인 없이 저장돼요.

최근 작업아직 기록된 작업이 없어요.
규칙 관리

실리태번에 저장한 연결 프로필을 선택해요. 별도 프로필을 고르면 RP용 메인 API를 바꾸지 않고 그 AI가 규칙을 정리해요.

세세하게는 작은 결정과 변화까지, 균형은 다음 전개에 필요한 내용을, 의미 중심은 큰 사건 위주로 모아요. 날짜·시간·장소가 정해진 일정과 명시적인 약속·거절·취소·정정·비밀은 모든 강도에서 반드시 수집해요.

1 이상의 정수를 직접 입력하면 그 값 그대로 저장해요. 기본값은 AI 답변 1개마다 새 규칙을 갱신해요.

갱신 주기가 50 이상이면 정리되기 전에 오래된 메시지가 최근 100개 범위에서 빠질 수 있어요.

자동 청소 시작 개수는 5~40개로 정할 수 있어요. 활성 규칙은 최대 40개이며, 정리용 AI가 만든 청소안을 JEV가 원문과 기존 규칙으로 다시 승인한 뒤 안전한 병합·종료만 적용해요. 직접 추가하거나 자동 변경 잠금한 규칙은 건드리지 않아요.

최근 100개 재수집 · 장면 한정 규칙 관리

자동으로 만든 기존 규칙을 비우고 최근 100개를 처음부터 다시 수집해요. 직접 추가하거나 자동 변경 잠금한 규칙은 유지해요.

장면 한정 규칙은 현재 장면이나 가까운 몇 턴에만 필요한 사실이에요. 모두 끄기는 삭제하지 않고 검사에서 제외하며, 각 규칙의 ‘다시 켜기’로 복구할 수 있어요.

JEV 연결

100LOG 사용 중에는 일반 답변·재생성·스와이프를 모두 숨은 초안으로 받은 뒤 JEV가 현재 규칙 전체와 비교해요. 이상이 없으면 표시하고, 충돌이 있을 때만 메인 AI 재작성과 재검수를 한 번 더 실행해요.

정상 답변은 ‘메인 AI 초안 1회 + JEV 검수 1회’만 사용해요. 재검수 후에도 충돌이 남은 경우에는 답변을 표시하지 않고 오류 토스트로 알려요.

API 키를 입력해 주세요

JEV 키는 새 규칙 자체가 원문과 맞는지 먼저 확인하고, 인물별 ‘알고 있음/아직 모름’도 함께 검증해요. 이름만 언급되었거나 일부 내용만 아는 인물에게 전체 사실을 넘기지 않아요.

마지막 오류

마지막 오류 1건만 이 브라우저에 보관해요. 새 오류가 나면 이전 오류를 덮어쓰며, 정상 작동이나 지연 안내는 기록하지 않아요. 추가 API 호출과 원문·인물명·키 기록은 없어요.

문제가 생기면 ‘오류 복사’로 전달해 주세요. 새로고침해도 마지막 오류는 유지돼요. 서버 내부나 다른 확장 오류 전체를 기록하는 기능은 아니에요.

개발자 모드 · 맞춤 규칙 주입
