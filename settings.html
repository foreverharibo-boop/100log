이야기는 네가, 기억은 메모리콩이.

핵심은 기억하고, 달라지면 고치고, 끝나면 정리해요.

처음이라면 · 딱 이것만 알아두세요

설정에서 기억을 정리할 AI의 연결 프로필을 고르고 평소처럼 RP하세요. 설정한 답변 수가 쌓이면 AI가 기억을 자동으로 추가·갱신해요. 후보를 하나씩 승인할 필요 없어요.

‘내일 만나자’는 약속으로 기억하고, 실제로 만나면 지난 기억으로 보내요. 계획만 했거나 결과가 애매하면 완료 처리하지 않아요. 새 기억은 한국어로 요약해요.

잘못된 것만 수정하거나 삭제하면 돼요. ‘보호’한 기억은 AI가 자동 변경하지 않아요. 새 답변 뒤에 정리용 API가 추가로 호출돼요.

지금 기억 중
직접 추가 · 기존 기억 갱신

직접 쓴 기억은 자동 변경되지 않도록 보호해요. AI가 관리하게 하려면 보호를 해제하세요.

완료된 일 · 바뀌기 전 상태

평소 답변에 다시 넣지 않아요. 잘못 정리된 기억은 복원할 수 있어요.

이전 버전의 미승인 후보

예전 후보는 그대로 보관했어요. 새 자동 기억은 승인 없이 저장돼요.

한국어 번역

저장된 기억과 출처를 번역해요. 전체 번역은 기존 번역도 다시 만들어요. 원문은 보관하고, RP 채팅 자체는 바꾸지 않아요.

기억을 관리할 AI

실리태번에 저장한 연결 프로필을 선택해요. 별도 프로필을 고르면 RP용 메인 API를 바꾸지 않고 그 AI가 기억을 정리해요.

기본값은 답변 3개마다 정리하고, 관련성·중요도가 높은 기억을 최대 12개 전달해요. 지금 정리는 주기를 기다리지 않고 실행해요.

현재 기억 중 관련성·중요도에 따라 최대 20개를 전달해요. 지난 기억은 제외해요.

이전 대화 가져오기 · 장면 관리

기존 대화가 많다면 한 번 가져오세요. 처음부터 읽어 핵심 기억을 자동 저장해요. 긴 대화는 여러 번 API를 호출해요.

선택 기능 · Jev 답변 검수

Jev는 기억을 만들거나 저장하지 않아요. 공개되기 전 답변이 현재 기억과 충돌하는지만 판정하고, 충돌하면 메인 AI에 한 번 수정을 요청해요. 자동 기억만 사용할 때는 Jev 키가 필요 없어요.
